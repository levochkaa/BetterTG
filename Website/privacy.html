Privacy Policy

Effective October 25, 2026

BetterTG is an open-source Telegram client for iOS made by Lev Poznyakov. This policy explains what data the app and its push notification server handle. "We" means the BetterTG project.

Your Telegram data

BetterTG connects to Telegram's servers directly through TDLib, Telegram's official client library. Your messages, contacts, media and account details travel between your device and Telegram and are stored on your device. Telegram handles them under the Telegram Privacy Policy. BetterTG doesn't send them to us, with the one exception of push notifications described below.

Push notifications

Telegram delivers notifications to apps like BetterTG only through Web Push, which an iPhone app can't receive on its own. While Notifications via BetterTG Server is on in Settings → Notifications and Sounds, which it is by default, BetterTG registers your device with our push server at push.bettertg.su. The server relays Telegram's notifications to Apple Push Notification service, which shows them on your device.

For each registered device the server stores:

  • a random installation ID and a secret the app uses to manage it;
  • the device's Apple push token, encrypted;
  • the push environment, the app's bundle ID, the app and iOS versions;
  • an App Attest public key and its receipt, encrypted, which prove that requests come from a genuine copy of the app;
  • the Web Push keys Telegram encrypts notifications with, the private ones encrypted;
  • when the device registered, was last seen and last received a notification.

Telegram sends each notification to the server encrypted. The server decrypts it in memory to build the notification you see, so it processes what the notification contains: the sender's name, the chat's title, a preview of the message and the identifiers of the chat and message. An encrypted notification waits in a queue until it is delivered, and one that can't be delivered is kept for up to an hour. The decrypted content is kept for up to 15 minutes so that the app's notification extension can fetch it, then deleted. The server doesn't keep message content anywhere else.

The server can't sign in to Telegram, read your chats or send messages for you. It never receives your phone number or your Telegram login.

Logs

The server's logs and metrics leave out message content, push tokens, keys and chat or message identifiers. Your IP address is held for up to a minute to limit request rates. The web server doesn't keep access logs.

Turning it off and deleting your data

Turning off Notifications via BetterTG Server stops Telegram from sending notifications for your device to us and deletes its registration, push token and keys from the server at once. If the device is offline, the app deletes them when it next connects. With the setting off, BetterTG shows notifications only while it is running.

Logging out of an account deletes that account's Web Push keys from the server. If you delete the app with the setting on, the server disables your device's registration once Apple reports that its push token is no longer valid. Turn the setting off before deleting the app to remove the registration at once.

Analytics and advertising

BetterTG has no analytics, advertising or tracking. If you choose to share crash reports with app developers in iOS settings, Apple passes them to us under Apple's privacy policy.

Services we rely on

  • Telegram, for everything you do in your account.
  • Apple, for push notifications and App Attest.
  • A rented server that runs the push relay.

Your own server

BetterTG and its push server are open source. A copy of the app built from the source can use its own push server or none, and then this policy's push section doesn't apply to it.
