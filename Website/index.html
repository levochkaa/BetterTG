BetterTG

A Telegram client for iOS

Source on GitHub

What it is

BetterTG is an open-source Telegram client for iPhone. It is written natively in UIKit on top of TDLib, follows the official Telegram app's behaviour and keeps its own look.

  • Chats, folders, archive and search.
  • Messages with media, voice and video messages, stickers, custom emoji and reactions.
  • Rich notifications with quick replies.
  • Several accounts on one device.

BetterTG is in development. Build it from the source to try it.

BetterTG is an independent project. It is not affiliated with or endorsed by Telegram.
